药房流水导出助手  v1.0   使用说明
==================================================

一、这是干什么的
--------------------------------------------------
把卫生站卖药软件里的“药品销售流水”，按你选的日期范围，导出成一个 Excel 文件。
Excel 里有两个工作表：

  1) 销售明细：每一笔卖出的药
     销售日期、单据号、药品名称、规格、单位、数量、单价、金额

  2) 按药品汇总：这段时间每种药卖了多少、卖了多少钱、多少笔

特点：
  · 全程在本机运行，不联网、不上传任何数据
  · 导出的是标准 .xlsx，WPS 和 Excel 都能打开
  · 电脑上不需要安装 Excel / WPS，也不需要装其它运行库
  · 能自动识别 SQL Server、Access、SQLite、DBF 这几种常见数据库
  · 销售明细和销售单头分成两张表的软件，可以用“关联主表”把日期接上
  · 会自动读软件配置文件里的数据库连接串（数据库在别的电脑上、或用了账号密码时有用）
  · 导出一次后会记住配置，下次选“方案：上次使用”直接出表


二、第一次使用（3 步）
--------------------------------------------------
第 1 步：双击 DrugFlow.exe

第 2 步：等几秒，程序会自动扫描这台电脑上的卖药软件。
        扫描到的数据库会出现在左上角“数据源”下拉框里。
        · 先选带 ★ 的，或者名字像你家用的那个软件
        · 第一项“示例数据”只是演示，不是真实数据

第 3 步：选好数据源之后
        · “数据表”一般会自动选中销售流水表
        · “日期字段 / 药品名称 / 数量 / 单价 / 金额”会自动对上；
          对不上就自己在下拉框里选一下
        · 选日期范围（今天 / 昨天 / 本月 / 上月 有快捷按钮）
        · 点“预览数据”，看看下面的表格对不对
        · 点“导出 Excel”，选一个保存位置

导出的文件名类似：药品销售流水_20261001-20261024.xlsx


三、日期在另一张表里怎么办（关联主表）
--------------------------------------------------
如果“日期字段”下拉框里没有合适的，或者预览出来的日期是空的，
说明这家软件把销售单头和药品明细分开存了。

这时点“数据表”右边的“关联主表…”，按提示选：
  · 主表：那张有日期、有单据号的表（名字常带“单头 / 主表 / 销售 / Sale”）
  · 明细表字段 和 主表字段：都选“单据号”（把两张表对起来）
  · 主表日期字段：选“销售日期”

点“确定关联”，上面的查询 SQL 会变成两张表的关联查询，
再按正常流程预览、导出即可。


四、如果扫描不到你的软件
--------------------------------------------------
点右上角“生成诊断报告”，程序会在“文档”文件夹里生成一个 txt 文件。
把这个 txt 发给我（微信传文件即可），我根据里面的软件名、数据库位置、
表名和字段名继续适配。

报告里只有软件名、安装路径、数据库位置、表名、字段名，
没有药品明细，也没有顾客信息，也不用担心泄露。

也可以点“手动连接”，直接指定：
  · SQL Server（填连接串）
  · Access 文件（浏览选 .mdb / .accdb）
  · SQLite 文件（浏览选 .db / .sqlite）
  · 其它 ODBC（Firebird、MySQL 等，需要本机有对应驱动）


五、常见问题
--------------------------------------------------
1. 提示“连接失败”
   先把卖药软件打开并登录，再点“自动扫描”；
   还不行就点“手动连接”，选 SQL Server，按提示填连接串。

2. 预览是空的，或者日期范围对不上
   有些软件把日期存成文本（比如 20260124 或 2026/01/24）。
   把“日期格式”下拉框换成对应格式（yyyyMMdd 或 yyyy/MM/dd），
   再点一次“预览数据”。
   如果怎么换都不对，多半是日期在另一张表里，看第三节“关联主表”。

3. 金额都是 0
   “金额”字段没选对。在“金额”下拉框里换一个；
   或者只选“数量”和“单价”，程序会自己算金额。

4. 360 / 火绒 报毒、每次打开都弹窗
   这是误报：程序不联网、不写开机启动、不读取别的程序。
   让弹窗消失的办法：
   · 360：弹窗里选“允许”，并勾选“不再提醒”；
     或打开 360 安全卫士 → 木马查杀 → 右下角“信任区” → 添加目录，
     选中 DrugFlow.exe 所在的整个文件夹
   · 火绒：弹窗选“允许”；或 火绒 → 防护中心 → 信任区 → 添加文件/目录
   · 如果文件被隔离：先在隔离区恢复，再按上面加信任
   想要“任何电脑上都不报”，只有给程序买代码签名证书（要花钱，一般是企业办）。

5. 换电脑 / 重装系统
   把 DrugFlow.exe 整个复制过去就能用，不需要安装。


六、重复使用：方案 / “上次使用”
--------------------------------------------------
导出成功后，程序会自动把这次用的“数据源 + 数据表 + 字段对应”存成一个方案。
下次打开程序，“数据源”下拉框里会多一项“方案：上次使用”。
选中它，直接选日期、点导出就行，不用再挑表、挑字段。

如果别人（比如帮你做工具的人）发给你一个 .ini 方案文件：
  1. 点窗口最下面右边的“导入方案文件…”
  2. 选中那个 .ini 文件
  3. 它会以“方案：xxx”出现在“数据源”里，选中即可

方案文件存放在：C:\Users\你的用户名\AppData\Roaming\DrugFlow\profiles


七、系统要求
--------------------------------------------------
Windows 7 / 10 / 11
.NET Framework 4.0 以上（Windows 10、11 自带；Win7 一般也有）
不需要 Excel、WPS。

读 SQLite 数据库时：
  · Windows 10 / 11 自带 SQLite 运行库，直接可用
  · Win7 需要卖药软件目录里有 sqlite3.dll（一般都有）

--------------------------------------------------

使用说明.txt       本文件

九、给帮忙做工具的人（技术备注）
--------------------------------------------------
· 数据访问：SQL Server（System.Data.SqlClient）、Access（ACE/Jet）、
  SQLite（winsqlite3.dll / sqlite3.dll，DllImport，无第三方库）、
  dBASE/FoxPro DBF（ODBC），以及任意 ODBC 数据源
· 明细表 + 主表关联：LEFT JOIN，日期取自主表；明细列逐个列出（兼容 Access）
· 会从安装目录的 .ini/.config/.xml 里提取 SQL Server 连接串并试连（支持 SQL 账号），
  报告和界面里密码一律打码显示
· SQL Server 用 SqlClient 连不上、但错误像 TLS/握手问题时，会自动改用系统 ODBC 驱动再试一次
· 诊断报告包含已安装的 ODBC 驱动、数据库服务状态，便于远程判断
· 不读取其它进程信息、不含密码/加密功能、不联网、不写开机启动——尽量降低杀软误判
· 程序是 32 位 .NET Framework 程序，单文件，无第三方依赖
· 生成 xlsx 是手写 OOXML + ZIP（DeflateStream + 自实现 CRC32），不依赖 Office
· 源码：src\*.cs，编译脚本：build.ps1（用系统自带 csc.exe，无需联网）
